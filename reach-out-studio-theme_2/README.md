# Reach Out Studio — Shopify theme

Custom Online Store 2.0 theme built on Shopify's Skeleton starter.
Warm neutral design system (bone / espresso / wheat) with a drop system for **Daily Bread Club**.

## What's inside
- **Drop system:** countdown (one date in Theme settings), waitlist form (customers tagged `dbc-waitlist`), locked "coming soon" products, members-only early-access page, drop-themed password page.
- **Sections:** hero, scrolling text, image with story, moments, featured products, content band, early access, product, collection, cart drawer, header, footer.
- **Blocks:** eyebrow, heading, text, button, countdown, waitlist form.

## Setup
1. Online Store → Themes → Add theme → Connect from GitHub → this repo, `main` branch.
2. Theme settings → Daily Bread Club drop: set the date and the drop collection.
3. Pages: create "Daily Bread Club" (template `page.daily-bread-club`) and "Early access" (template `page.early-access`).
4. Settings → Custom data → Products: add `custom.meaning` (multi-line text) and `custom.care` (multi-line text).
5. Navigation: `main-menu` and `footer` menus.
